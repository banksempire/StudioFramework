# Multi-tab workspace

## Drag to tile

I want the tab in workspace can be drag to tile (DTT). Just like on vscode. 

When DTT, the dragged tab will always try to take half of the drag-to tile. (Top/buttom tiling or left/right tilling)

Each tile has a min height and min width. Size of each tile should be maintained on poportion during workspace resizing. The poportion can be breaked only if min height and width reached.

## Drag to move

Example, when there are 3 tab (a, b and c) opened, 2 (a, b) on the left tile, 1 (c) on the right tile. I can drag tab `b` to the right.
